How to Use Icons

To use icons in your views, use the following format:

<i class="fas fa-icon-name"></i>

Examples:
- <i class="fas fa-home"></i>      → Home icon
- <i class="fas fa-user"></i>     → User icon
- <i class="fab fa-discord"></i> → Discord icon (note: fab for brands)
